# C-Through

*A beginner-friendly C interpreter, written in C, with its inner workings laid bare.*

C-Through is built for people learning C and for anyone curious about how interpreters work.

- **If you're learning C:** run C code without a compile step, using a slightly more lenient interpreter that warns about bad practices, gives beginner friendly error messages, and offers a step-by-step execution mode.
- **If you're curious about interpreters:** see how each stage of an interpreter is built and how the stages fit together, through an organized, readable pipeline with the design decisions explained in the docs.

## Status

Early development. The lexer is in progress. The parser and the evaluator have not been started yet.

Not available yet: the step by step execution mode, the bad practice warnings, and the docs.
